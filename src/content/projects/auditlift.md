# AuditLift

[AuditLift](https://auditlift.app) is a security readiness platform built for growing companies that are starting to run into enterprise security reviews, compliance requirements, and the inevitable pile of questionnaires that comes with selling to larger customers.

The idea came from a problem I had seen from the other side: companies often do a lot of the right security work before they are formally "audit ready," but proving it is fragmented across policies, screenshots, tickets, infrastructure, and institutional knowledge. When a prospect asks about SOC 2, PCI-DSS, ISO 27001, or a specific control, figuring out what is already covered and what is actually missing becomes its own project.

AuditLift tries to make that gap visible.

It maps policies and evidence against common security frameworks, shows which controls are already covered, surfaces what is still missing, and keeps the supporting evidence organized in one place. Teams can generate and edit policies, assign control ownership, track readiness, and export a structured security package when an auditor or prospect asks for it.

The product currently supports **SOC 2, PCI-DSS, and ISO 27001**, with framework mapping, policy generation, evidence management, gap visibility, team collaboration, and security package exports built into the workflow.

What interests me most about the project is the space between security work and compliance work. They overlap, but they are not the same thing. A company can have sensible security practices and still struggle to demonstrate them. AuditLift is an attempt to make that translation simpler, especially for smaller teams that do not need, or cannot justify, a heavyweight enterprise GRC platform.
